# Research interface recommendations

Keep the Space Empires IV technology tree, prerequisites, costs and allocation rules. Reduce how much a new player must interpret at once.

**Civilization VI** exposes its full tree through a Technology Tree button, showing the current project and later technologies. The useful lesson is to keep wider context accessible without making every choice start with the entire tree. [Official 2K manual](https://downloads.2kgames.com/civilization/vi/manuals/eu/CIV_VI_25TH_ONLINE_MANUAL_ENG.pdf).

**Endless Space 2** groups research into major domains and uses a research queue. Its manual describes inspecting bonuses and capacities before selecting a technology. The useful lesson is grouping by purpose and making concrete benefits easy to inspect. [Official manual](https://cdn.steamstatic.com/steam/apps/392110/manuals/ES2_PC_OM_JAN_2018_210x297_UK_HR.PDF).

My recommendation is Available technologies first, category filtering, exact unlocks in Details, and a compact priority queue with this-turn allocation and completion estimates. Keep All technologies available for planning. These presentation choices do not import either game's progression rules.

Update 21 implements Available/All browsing, category filtering and collapsible allocation options. Existing native unlock details, allocation and turn estimates remain in research cards. Original technology order is preserved within the filtered list.

Priority allocation is a sensible beginner default because the first project has a clear priority. Even splitting remains useful for some strategies and stays available. New human games start with it off; existing saves retain their settings. This is a default preference, not a claim that all players research the same way.

A later goal browser could highlight existing prerequisites for better engines, shields or colonization. That is a recommendation, not an implemented feature in this release.
